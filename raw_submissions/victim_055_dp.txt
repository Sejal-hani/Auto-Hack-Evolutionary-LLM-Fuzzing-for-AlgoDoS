**PROBLEM STATEMENT**

You are given an array `a` of pairwise distinct integers from `0` to `n`. Consider the following operation: consecutively for each `i` from `1` to `n` in this order, replace `a_i` with `MEX(a_1, a_2, …, a_n)`. Here `MEX` of a collection of integers `c_1, c_2, …, c_m` is defined as the smallest non-negative integer `x` which does not occur in the collection `c`. For example, `MEX(0,2,2,1,4)=3` and `MEX(1,2)=0`. Print the array after applying `k` such operations.

**LIMITS**

- Time limit per test: 2 seconds
- Memory limit per test: 256 megabytes
- Number of test cases: `t` (1≤`t`≤10^5)
- Size of the array: `n` (1≤`n`≤10^5)
- Number of operations: `k` (1≤`k`≤10^9)

**CODE**

```python
t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    k = k % (n + 1)
    ch = (n + 1) * n // 2 - sum(a)
    a = (a + [ch]) * 2
    print(*a[n + 1 - k : : n - k + n + 1])
```
