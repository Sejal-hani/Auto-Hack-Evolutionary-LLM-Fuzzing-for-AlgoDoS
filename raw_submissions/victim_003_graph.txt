**PROBLEM STATEMENT**

Given a graph with `n` nodes and `m` edges, find the maximum number of edges that can be added to the graph such that it remains a forest (i.e., a graph with no cycles).

**LIMITS**

* `1 ≤ n ≤ 2 * 10^5`
* `1 ≤ m ≤ 2 * 10^5`
* `1 ≤ u, v ≤ n` for each edge `(u, v)`

**CODE**

	return t;
}

}

			if(!vis[i]){
				dfs(i);
				ans++;
			}
		}
		printf("%d\n",ans-1);
	}
}
