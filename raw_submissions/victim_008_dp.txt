**PROBLEM STATEMENT**

Stanley defines the beauty of an array `a` of length `n`, which contains non-negative integers, as follows: `∑i=1n⌊ai/k⌋`, which means that we divide each element by `k`, round it down, and sum up the resulting values. Stanley told Sam the integer `k` and asked him to find an array `a` of `n` non-negative integers, such that the beauty is equal to `b` and the sum of elements is equal to `s`. Help Sam — find any of the arrays satisfying the conditions above.

**LIMITS**

- Time limit per test: 1 second
- Memory limit per test: 256 megabytes
- Number of test cases: `1 ≤ t ≤ 1000`
- Array length: `1 ≤ n ≤ 10^5`
- Divisor: `1 ≤ k ≤ 10^9`
- Beauty: `0 ≤ b ≤ 10^9`
- Sum of elements: `0 ≤ s ≤ 10^18`
